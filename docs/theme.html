Dageraad & Gloed

One brand, one sun cycle. Light mode is Dageraad — signal red melting into warm paper; dark mode is Gloed — the same red as an ember glow on charcoal. Toggle above to see both.

Color tokens

Each token's light and dark value, shown side by side regardless of the page's current mode.

The red budget

Brand red is rationed to five places: the hero, the primary CTA, map pins, the live dot, and links or eyebrows. Nowhere else — every other neutral stays warm charcoal or paper.
